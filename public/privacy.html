GitVisualizer

Privacy Policy

Last updated: May 13, 2026

GitVisualizer is provided by Miz Causevic / Kinetic Gain. The app visualizes public GitHub profile and repository data for the GitHub username entered by the user.

Data We Process

GitVisualizer sends the GitHub username you enter to the public GitHub API in order to fetch public profile and repository information. The app does not ask you to create an account, does not request GitHub authentication, and does not collect passwords, payment information, contacts, location, camera data, microphone data, health data, or device identifiers.

How Data Is Used

The GitHub username is used only to load and display the requested public GitHub profile analysis. Public GitHub API responses may be cached by the browser or service worker to improve loading behavior.

Sharing

GitVisualizer does not sell user data. Requests for GitHub profile information are sent to GitHub because that is required for the app's core functionality. GitHub's own handling of GitHub API requests is governed by GitHub's terms and privacy policy.

Retention And Deletion

GitVisualizer does not maintain user accounts or a server-side user database. Browser caches and service worker caches can be cleared by clearing site data for gv.kineticgain.com in your browser or Android app settings.

Security

GitVisualizer is served over HTTPS and makes HTTPS requests to the GitHub API. No sensitive account credentials are requested by the app.

Children

GitVisualizer is intended for developers, hiring teams, operators, and technical professionals. It is not directed to children under 13.

Contact

For privacy questions, contact miz@kineticgain.com.
