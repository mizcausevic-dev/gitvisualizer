Delete Data

Last updated: May 13, 2026

GitVisualizer does not require an account and does not maintain a developer-owned server-side user database. The app uses public GitHub API data for the GitHub username entered by the user.

How To Request Deletion

To request deletion guidance or ask us to review any data associated with GitVisualizer, email miz@kineticgain.com with the subject line "GitVisualizer data deletion request".

What Can Be Deleted

Because GitVisualizer does not create user accounts or store searched GitHub usernames in a Kinetic Gain database, there is usually no server-side user record to delete. If future support records are created through email, we can delete those support records on request unless retention is required for security, legal, or abuse-prevention reasons.

Local App Data

Users can clear local GitVisualizer app or site data from Android app settings, Chrome site settings, or browser storage settings for gv.kineticgain.com. This clears local cache and service worker data stored on the device.

Data We Do Not Control

Public GitHub profile and repository data is provided by GitHub. To modify or delete GitHub account data, users must manage that data through GitHub.
